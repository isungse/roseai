## 작업 목적

첫 방문자가 ROSE-AI에 어떤 업무를 맡길 수 있고 어떤 결과를 받을 수 있는지 이해할 수 있도록 4장 슬라이드의 소개글을 수정했다. 특정 업종이나 세부 기능에 한정되지 않도록 업무 표현은 포괄적으로 유지했다.

## 배포된 한국어 소개글

### 01. 반복 업무 파악

**커피 한잔의 여유를 돌려 드립니다.**

매일 반복되는 업무를 맡겨 주세요.  
ROSE-AI는 현재의 업무 방식을 살펴보고, 꼭 필요한 AI 자동화를 설계합니다.  
불필요한 과정을 줄이고, 바로 활용할 수 있는 도구를 제공합니다.  
반복 업무에 쓰던 시간을 더 중요한 일에 사용하세요.

### 02. 반복 과정 개선

**하루의 마무리를 조금 더 가볍게.**

매일 사람의 손을 거치는 반복 업무를 맡겨 주세요.  
흩어진 정보와 반복되는 과정을 정리해, 더 빠르고 편리하게 일할 수 있는 도구를 만듭니다.  
처리하는 시간을 줄이고, 검토와 판단에 집중하세요.

### 03. 업무 흐름 연결

**따로 하던 일을 하나의 흐름으로 연결합니다.**

여러 단계와 도구를 거쳐 처리되는 업무를 맡겨 주세요.  
현재의 업무 방식에 AI와 자동화를 연결해, 자연스럽게 이어지는 업무 흐름을 만듭니다.  
반복되는 과정은 시스템이 맡고, 중요한 판단은 사람이 담당하도록 설계합니다.

### 04. 실행 상태 확인

**자리를 비워도, 진행 상황은 알 수 있도록.**

자동화의 실행 상태를 계속 확인하는 일도 맡겨 주세요.  
실행 결과를 기록하고, 감지한 오류와 확인이 필요한 일을 알려주는 기능을 함께 설계합니다.  
필요한 순간에만 확인하고, 나머지 시간은 편하게 보내세요.
