처리하는 시간을 줄이고, 검토와 판단에 집중하세요.

### 03. 업무 흐름 연결

현재의 업무 방식에 AI와 자동화를 연결해, 자연스럽게 이어지는 업무 흐름을 만듭니다.  
반복되는 과정은 시스템이 맡고, 중요한 판단은 사람이 담당하도록 설계합니다.

### 04. 실행 상태 확인

**자리를 비워도, 진행 상황은 알 수 있도록.**

자동화의 실행 상태를 계속 확인하는 일도 맡겨 주세요.  
실행 결과를 기록하고, 감지한 오류와 확인이 필요한 일을 알려주는 기능을 함께 설계합니다.  
필요한 순간에만 확인하고, 나머지 시간은 편하게 보내세요.

## 세션 3 — 슬라이드 02 를 낮 사무실로 교체, 순서 재배열 (Claude Code)

### 작업 목적

밤 사무실 사진을 빼고 "아침 → 낮 사무실 → 퇴근 → 캠핑" 하루 흐름으로 재배열. 낮 사무실은 "회의 중에도 빈 책상의 PC 는 AI 에이전트가 움직인다" 연출.

### 이미지 생성

- Higgsfield MCP 사용. GPT Image 2.5 · Recraft V4.1 은 무료 플랜에서 "Requires basic plan or higher" 로 거부 → Google Nano Banana Pro 로 2048² 후보 2장 생성 (1:1, 2k).
- 사용자가 후보 A 를 편집(서 있는 인물을 빨간 사원증의 여성으로)해 `Downloads\office-day-수정.png` (1254²) 로 저장 → 1600² JPEG q86 변환 → `public/images/showcase-02.jpg`.

### 변경 파일

- `public/images/`: 밤 사무실(구 03) 삭제, 퇴근(구 02) → 03 으로 `git mv`, 낮 사무실 → 02 신규

### 세션 3 추가 — 04 캠핑 소개글 재작성

기능 설명 톤("실행 상태 확인 · 오류 감지")이 캠핑 장면과 맞지 않아, 인물 시점으로 다시 썼다. "여유롭게 쉴 수 있는 이유 = AI 에이전트가 일하고 있다"를 제목이 선언하고 본문이 뒷받침한다.

**당신이 쉬는 동안에도, 일은 계속됩니다.**

별을 보는 이 시간에도 AI 에이전트는 자리를 지키고 있습니다.  
결과를 정리하고, 살펴봐야 할 일이 생기면 그때만 조용히 알려줍니다.  
그러니 지금은, 이 시간을 온전히 즐기세요.

- EN 동일 구조로 반영. 1440 기준 KO 본문 3줄 · EN 4줄, 900px 높이 스크롤 없음. lint · build 통과.
